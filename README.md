# TaskManager REST API - Spring Boot

A full-stack Task Management REST API built with Spring Boot and deployed on Railway with MySQL database.

## 🚀 Live Demo

**API Base URL:** `https://taskmanagerapi-production-4b31.up.railway.app`

**Example Endpoint:** [https://taskmanagerapi-production-4b31.up.railway.app/api/tasks](https://taskmanagerapi-production-4b31.up.railway.app/api/tasks)

## ✨ Features

- ✅ Create, Read, Update, Delete (CRUD) operations for tasks
- ✅ RESTful API architecture
- ✅ MySQL database integration
- ✅ Deployed on Railway cloud platform
- ✅ Spring Boot backend
- ✅ JPA/Hibernate ORM
- ✅ JSON response format
- ✅ Public API access

---

## 🛠️ Tech Stack

**Backend:**
- Java 21
- Spring Boot 3.5.11
- Spring Data JPA
- Hibernate 6.6

**Database:**
- MySQL 8.0
- Railway MySQL instance

**Deployment:**
- Railway (Cloud Platform)
- Docker containers

**Tools:**
- Maven 3.9
- MySQL Workbench
- Postman (API testing)
- Git & GitHub
